# Задачи для Claude Code (часть A, без ИИ)

Правила: делай по порядку. СНАЧАЛА по каждому пункту проверь, что уже есть в коде
(часть функций уже сделана — не дублируй, дорабатывай существующее). После каждого
пункта: сборка без ошибок, прогон FineryTests (xcodebuild test -scheme Finery
-destination 'platform=iOS Simulator,name=iPhone 16' -only-testing:FineryTests),
отдельный git-коммит, git push. Backend не трогай. Reduce Motion и Dynamic Type
уважай. В конце — короткий отчёт: что сделал, что проверить на телефоне.

ВАЖНО СНАЧАЛА: у меня в рабочей папке ~28 незакоммиченных файлов (Face ID, HIG-правки,
Dashboard, Tax и др.). Прежде чем начинать, покажи git status и закоммить их
логическими коммитами (по темам) и запушь. Потом начинай задачи.

1. РУССКАЯ ЛОКАЛИЗАЦИЯ. В окне быстрого ввода кнопки "Cancel"/"Done" по-английски.
   Сейчас developmentRegion = en. В project.yml: options.developmentLanguage: ru,
   knownRegions: [ru, en]; Info.plist CFBundleDevelopmentRegion = ru. Добавь
   Localizable.xcstrings с русскими строками для системных диалогов AppIntent.
   Проверь, что xcodegen generate не теряет настройки, и что кнопки стали
   "Отмена"/"Готово".

2. ПОДСКАЗКА ПРО ДИКТОВКУ. В QuickInputGuideView (Настройки) и в тексте окна
   "Что добавить?" упомяни: "Нажмите 🎤 на клавиатуре и продиктуйте". Свою запись
   звука НЕ добавляй. Заодно: в project.yml есть ключи NSMicrophoneUsageDescription /
   NSSpeechRecognitionUsageDescription — проверь, используются ли они ещё; если нет,
   предложи убрать (не удаляй без подтверждения).

3. НАЛОГОВАЯ ПОДУШКА НА ЭКРАНАХ. Подсказка "Отложи X ₽" уже есть при добавлении
   дохода (AddTransactionView). Добавь на экран налогов (TaxView) и одной строкой на
   Dashboard: "Из доходов этого месяца X ₽ — налог, не тратьте". Считай через
   TaxCalculatorService по SharedDataService.transactions, ничего не хранить —
   только computed. Добавь 3 теста (НПД 4%, УСН 6%, нулевой доход).

4. НАПОМИНАНИЯ — ДОРАБОТКА СУЩЕСТВУЮЩЕГО. NotificationService уже умеет: налог за
   5 дней, 28-е, лимит НПД, повторяющиеся. Чего не хватает — проверь и добавь:
   а) напоминание о просроченном неоплаченном счёте (N дней, по умолчанию 7;
      "Счёт для <клиент> на X ₽ не оплачен N дней"); если в модели счёта нет
      статуса/даты, скажи мне, не выдумывай;
   б) разрешение на уведомления сейчас запрашивается при запуске приложения
      (FineryApp.swift) — перенеси запрос на момент включения переключателя
      "Напоминать о налоге" в Настройках, с объяснением зачем;
   в) отдельные переключатели: налог / счета / лимит НПД;
   г) пересчёт и отмена запланированных уведомлений при изменении транзакций
      и счетов (через SharedDataService).

5. БЕЗОПАСНОСТЬ. В project.yml есть ключ ANTHROPIC_API_KEY: "" в Info.plist.
   Ключ в приложении недопустим (его можно достать из бандла). Убери ключ и
   проверь, не используется ли он в коде (grep). Не удаляй код, который его
   читает, без предупреждения — скажи, где он используется.
