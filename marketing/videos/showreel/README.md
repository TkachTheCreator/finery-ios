# Finery — промо-шоурил (Remotion)

Вертикальный ролик 1080×1920, 60 fps, 29 с, H.264 + AAC.
Готовый файл: `out/finery-showreel.mp4`.

## Что, для кого, где

- **Что:** iOS-приложение, которое ведёт учёт денег самозанятого и фрилансера и само считает налог.
- **Для кого:** блогеры, стримеры, фрилансеры, самозанятые. Боль: деньги приходят из пяти мест, налог считают руками, про 28-е вспоминают в последний день.
- **Где:** iPhone (iOS 18+). Приложения ещё нет в App Store, поэтому CTA: «Скоро в App Store · для iPhone · finery.pro».
- Источник фактов: `marketing/FINERY_BRAND_BRIEF.md`, `FINERY_MOTION_STYLE.md`, `PROMPT_VIDEO_V2.md`.

## Дизайн-решения

- Палитра и шрифт строго из брифа: эспрессо `#1A1510`, крем `#FAF8F3`/`#F2EADE`, золото `#CDA46D`, смысловые цвета (успех, расход) и пыльные цвета разделов. Шрифт Nunito 400–900 (замена SF Pro Rounded по брифу). Синего нет.
- Интерфейс Finery нарисован заново в векторе (`src/components/FineryUI.tsx`) по реальным экранам из `marketing/screens/`, а не растянутыми скриншотами. Данные из демо-аккаунта: 59 950 / 21 050 / 2 398 / 36 502 ₽. Логотип взят из контуров `FineryLogoMark.swift` (`src/components/logoPaths.ts`).
- Учтены правила из брифа: нет «Привет, …», чистая строка состояния 9:41, нет «Мой налог», нет ИИ-помощника и голосового ввода, нет обещаний экономии, CTA «Скоро в App Store».
- Весь текст внутри безопасной зоны Reels/TikTok: сверху ≥ 270 px, снизу ≥ 380 px, по бокам 64 px.
- **Осознанное отступление от брифа:** в брифе сказано «без глитча, зум-взрывов, вращений». Для шоурила по задаче «go crazy» я использовал резкие слэмы, тряску камеры, проходы сквозь объекты и 3D-вращения. Цвета, шрифт и тон бренда при этом не тронуты.

## Музыка и звук: источники и права

**Внешних треков и сэмплов в ролике нет.** Музыка и все звуки синтезированы с нуля скриптом `audio/make_audio.py` (numpy + scipy: осцилляторы, фильтры, шум, свёрточный ревёрб). Это оригинальная работа, сделанная для этого ролика, поэтому проблем с авторскими правами нет и Content ID её не узнает.

Почему не Mixkit: сеть окружения, в котором собирался ролик, закрыта для стоков (Mixkit, Pixabay, Free Music Archive, Freesound и других: ответ прокси 403). Плюс в своём треке ударные, стопы и тишина стоят ровно на склейках.

- Трек: оригинал, 120 BPM, ре минор, Dm–B♭–F–C, 29 с.
  - 0–4 с: хаус-грув, пинги уведомлений на 1/8
  - 4–8 с: стоп на вопросе, тревожный халфтайм, тики часов, перелистывание календаря, райзер с дробью
  - 8 с: дроп
  - 8–25 с: грув (бочка в четыре, клэп, хэты, басовые оффбиты, стэбы, арпеджио 1/16)
  - 25 с: финальный удар и хвост
- Звуки интерфейса (тоже синтез): тап, стук по спинке, тики клавиатуры, «динь» успеха, попы, свуши, удары, тики одометра.
- Мастер: −14 LUFS (EBU R128), true peak ≤ −1,5 dBTP, стерео 48 кГц, AAC 320 кбит/с.

### Заменить трек на Mixkit (по желанию)

1. Разрешить `assets.mixkit.co` в сетевых настройках окружения (или скачать трек локально).
2. Взять трек под Mixkit Free License (каталог https://mixkit.co/free-stock-music/, лучше electro/house около 120 BPM).
3. Положить его в `public/audio/` и заменить `staticFile('audio/finery_showreel.wav')` в `src/Showreel.tsx`. Сетка долей рассчитана на 120 BPM: трек с другим темпом нужно растянуть или поменять `BEAT` в `src/theme.ts`.
4. Вписать название, автора и ссылку на трек в этот раздел.

## Сборка

```bash
cd marketing/videos/showreel
npm install
python3 audio/make_audio.py              # -> public/audio/finery_showreel_raw.wav
ffmpeg -y -i public/audio/finery_showreel_raw.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 -ar 48000 public/audio/finery_showreel.wav
npx remotion studio src/index.ts         # превью
npx remotion render src/index.ts FineryShowreel out/finery-showreel.mp4 --crf 16 --audio-bitrate 320k
node scripts/stills.mjs <папка> 0 240 480 ...   # контрольные кадры
```

`remotion.config.ts` указывает на локальный Chromium (`/opt/pw-browsers/...`). На другой машине уберите `setBrowserExecutable`.
