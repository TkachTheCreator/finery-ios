# Finery — стиль моушена и раскадровки (для контент-завода)

Источник: разбор референса (запись ленты Instagram Revolut, 61 с). Берём ТОЛЬКО приёмы анимации и ритм. Не копируем кадры, логотипы, музыку, тексты и сами 3D-модели Revolut. Всё делается на палитре и шрифте Finery.

## 1. Что именно мы взяли из референса

| Приём в референсе | Как это выглядит | Наш аналог |
|---|---|---|
| Тёмная глянцевая студия | Тёмный фон, отражающий пол, неоновая кромка по краю объекта | Фон эспрессо `#1A1510`, отражающий пол, кромка золотом `#CDA46D` (вместо бирюзового неона) |
| Вращающийся предмет | Быстрый разворот/наклон 3D-объекта с motion blur, потом мягкая остановка | Телефон с Finery внутри: оборот 360° по Y, замедление в конце (ease-out), остановка анфас |
| Макро-пролёт камеры | Камера скользит по детали (чип, кромка), потом отъезд | Пролёт по карточке «Налоговая подушка», по цифре баланса, по кнопке «+» |
| Расслоение | Карта «разъезжается» на слои | Экран приложения разъезжается на слои: фон, карточки, цифры, кнопка (parallax по Z) |
| Карусель с блюром | Горизонтальный слайд с размытием движения | Свайп между экранами внутри телефона (баланс, операции, налоги) |
| Минималистичные подписи | По центру, 1–3 слова, светлый шрифт, точка в конце («Extra security.») | Подписи SF Pro Rounded, 1–3 слова, точка в конце: «Всё в одном экране.» |
| Печатающийся промпт | Строка ввода, фразы сменяют друг друга, белые линейные иконки | Строка «Что добавить?» — печатаем «кофе 350», «клиент Аня 15 000» → появляется операция |
| Резкий свайп-переход | Смахивание в следующую сцену | Смах телефона вбок, на его место въезжает следующая сцена |
| Сетка постов | Профиль-сетка из однотипных обложек | Единый вид обложек: тёмный фон, одна крупная цифра/фраза |

## 2. Палитра и шрифт (жёстко)

- Фон сцен: `#1A1510` (эспрессо), глубокий `#120F0A`.
- Светлый фон для «дневных» сцен: `#FAF8F3`.
- Текст на тёмном: `#F2EADE` (крем) или `#EDE8DE`.
- Акцент и «неон»: золото `#CDA46D`. Свечение — мягкое, радиус большой, прозрачность 0.25–0.45.
- Доход `#1A6B3C`, расход `#C04E35`, предупреждение `#9B6B00` — только как смысловые цвета в UI.
- Шрифт: SF Pro Rounded (Semibold для подписей, Bold для цифр, цифры моноширинные). Никаких других шрифтов.
- Запрещено: бирюзовый/синий неон из референса, любые элементы бренда Revolut.

## 3. Тайминги и кривые

- Ритм: смена плана каждые 0.8–1.5 с, короткие ролики 8–15 с, максимум 30 с.
- Базовый ease: ease-out cubic (быстрый старт, мягкая остановка). Для «пружины»: spring ≈ как в приложении (response 0.50, damping 0.82).
- Вращение телефона: 0–0.6 с разгон, 0.6–1.4 с быстрый оборот с motion blur, 1.4–2.0 с торможение до анфаса.
- Подпись: появляется fade + сдвиг вверх 12 px за 0.35 с, держится ≥1.2 с (читаемость на телефоне).
- Расслоение: слои разъезжаются за 0.6 с, держатся 1 с, собираются обратно 0.5 с.
- Motion blur: направленный, сила пропорциональна скорости; на финальном кадре блюра нет.
- Свечение: «дыхание» 3–4 с, как в Hero-карточке приложения.
- Reduce Motion в самом приложении учитываем: в записях демо приложения не показываем нарушающих это эффектов.

## 4. Сцена «Крутящийся телефон с Finery» (фирменный ролик)

Композиция: вертикаль 9:16, телефон по центру, занимает 60–70% высоты.

1. 0.0–0.5 с. Чёрный экран → золотая кромка загорается по контуру телефона (border trail, как в приложении, 4 с цикл, ускоренно).
2. 0.5–2.0 с. Телефон делает оборот по оси Y (обратная сторона → экран). На экране уже лежит живой экран Finery (запись демо-аккаунта).
3. 2.0–3.0 с. Остановка анфас, лёгкое покачивание (±3°). Подпись: «Все твои деньги. Один экран.»
4. 3.0–6.0 с. Макро-пролёт по главной цифре, потом по карточке налогов.
5. 6.0–9.0 с. Расслоение экрана, слои парят, подписываем 1–2 киллер-фичи.
6. 9.0–11.0 с. Телефон уходит свайпом, приезжает логотип Finery (spring со scale 0.3, shimmer 2 прохода) и таглайн.
7. 11.0–12.0 с. Кот-маскот выглядывает из-за логотипа (по желанию в мемных роликах).

Реализация: HyperFrames/Remotion (HTML+GSAP/CSS 3D transform: `rotateY`, `perspective`) либо псевдо-3D из заранее отрендеренных кадров. Экран приложения — видео с симулятора в рамке iPhone (рамка нейтральная, без брендинга Apple).

### Запуск приложения (запись 5.10, 00:33, 7,9 с, 60 fps) — готовый «кинематографичный» отрезок
