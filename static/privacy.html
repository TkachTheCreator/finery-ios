2. Какие данные мы собираем

2.1 Данные учётной записи

  • Имя
  • Адрес электронной почты
  • Пароль (хранится в зашифрованном виде, мы не имеем доступа к паролю в открытом виде)
  • Тип деятельности (самозанятый / личные финансы / ИП-ООО)
  • Налоговый режим (НПД / УСН и ставка)

2.2 Финансовые данные, которые вы вносите

  • Записи о доходах и расходах (сумма, дата, категория, описание)
  • Данные о клиентах, которых вы добавляете (имя, тип — физическое или юридическое лицо, статус)
  • Рассчитанные на основе введённых данных показатели (сумма налога, прогноз, лимиты)

2.3 Биометрические данные (Face ID / Touch ID)

Если вы включаете вход по Face ID/Touch ID — биометрические данные обрабатываются исключительно локально на вашем устройстве через системный механизм Apple (LocalAuthentication). Мы не получаем, не храним и не передаём эти данные на наши серверы.

2.4 Технические данные

  • Данные об использовании приложения для диагностики и устранения ошибок
  • Данные, необходимые для работы push-уведомлений (если вы их включили)

2.5 Данные, которые мы НЕ собираем

  • Мы не собираем данные о местоположении
  • Мы не используем данные для показа рекламы
  • Мы не отслеживаем вашу активность за пределами приложения

3. Как мы используем данные

Мы используем собранные данные для:

  • Предоставления функциональности приложения (учёт доходов/расходов, расчёт налогов, управление клиентами)
  • Расчёта налоговых показателей на основе введённых вами данных (носит справочный характер, см. раздел «Отказ от ответственности» в Условиях использования)
  • Отправки уведомлений о приближении налогового дедлайна или лимита дохода (если включено в настройках)
  • Технической поддержки и устранения неполадок

4. Где хранятся данные

Данные хранятся на сервере, расположенном на территории Российской Федерации, в соответствии с требованиями Федерального закона №152-ФЗ о локализации персональных данных граждан РФ.

5. Передача данных третьим лицам

5.1 Платёжные операции

Готовится к заполнению. После подключения ЮKassa: при обработке платежей мы передаём необходимые данные платёжному агрегатору в объёме, необходимом для проведения платежа, в соответствии с их политикой конфиденциальности.

5.2 ИИ-помощник

Готовится к заполнению. При использовании функции ИИ-помощника текст вашего запроса будет передаваться поставщику технологии ИИ для формирования ответа. Персональные финансовые данные не передаются без вашего явного запроса внутри диалога.

5.3 Курсы валют

Для функции мультивалютности мы обращаемся к открытому API Центрального Банка РФ для получения актуальных курсов валют. Персональные данные при этом не передаются.

Мы не продаём и не передаём ваши персональные данные третьим лицам для маркетинговых целей.

В соответствии с Федеральным законом №152-ФЗ вы имеете право:

  • Запросить информацию о том, какие данные о вас хранятся
